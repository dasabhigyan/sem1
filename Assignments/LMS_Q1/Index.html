Bash Command I Have Learnt

1.touch

File creation

The touch command creats a new,empty file. If the file already exits, it simply updates the file last-modfied timestamp instead of changing its content.
It's one of the simplest ways to create a file directly from the terminal.

syntax:touch filename

Example:touch notes.txt

Output:(no output - the file notes.txt is created silently in the current folder)

2.mkdir

Folder creation

The mkdir commands creats a new, empty folder (directory) at the location you specify.

Syntax: mkdir foldername

Example:mkdir project

Output:( no outpuut - the folder project is created in the current directory)

3.cd

Changing directory

The cd comannds changes the current working directory, moving you into a different folder in the terminal.

Syntax:cd foldername

Example:cd Project

Output:(prompt changes to show you are now inside ~/project)
